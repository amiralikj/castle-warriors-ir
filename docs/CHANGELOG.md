# رویدادنگار موج‌ها — جنگاوران قلعه

هر موج ساخت یک بخش مشخص از بازی است. بعد از هر موج: تست‌ها اجرا می‌شوند، با پروژه ادغام می‌شود و اینجا ثبت می‌شود.
ترتیب و تعریف کامل موج‌ها در [`docs/WAVES.md`](WAVES.md) است.

قالب هر یادداشت:

```md
## موج <شماره> — <عنوان>
- **وضعیت:** انجام شد / در حال ساخت
- **تاریخ:** <تاریخ شمسی>
- **چه ساخته شد:** ...
- **فایل‌های کلیدی:** ...
- **تست‌ها:** `npm test` — <تعداد> تست سبز
- **یادداشت:** ...
```
