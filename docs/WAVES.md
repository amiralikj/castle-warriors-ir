## روش کار هر موج

1. `npm run wave start <n>` — موج را فعال کن.
2. کد و تست همان موج را بنویس و `npm test` را سبز کن.
3. یادداشت موج را در `docs/CHANGELOG.md` بنویس.
4. `npm run wave finish <n>` — موج را تحویل بده (فقط اگر تست‌ها سبز باشند).
5. کامیت موج با پیام `wave <n>: <عنوان>` ثبت می‌شود.
6. `npm run wave verify` — بررسی نهایی سلامت پروژه و مستندات.
